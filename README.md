# Elevate UI

Lovable Prompt – Frontend UI Only

Build a high-fidelity frontend prototype from the provided wireframes.

General Requirements

Frontend only.

Do not create any backend, database, API routes, authentication logic, server files, or mock backend.

Use React + Vite + TypeScript.

Use Tailwind CSS for styling.

Use shadcn/ui components where appropriate.

Use Motion (Framer Motion) extensively for animations.

Use Lucide React for icons.

Follow the wireframe layout and functionality closely while significantly improving the visual design.

The final result should feel like a premium enterprise SaaS product rather than a basic dashboard.

Design Style

Aim for a combination of:

Apple-level smoothness

Linear-inspired minimalism

Modern enterprise dashboard

Futuristic but professional

Clean typography

Rounded cards

Glassmorphism where appropriate

Soft gradients

Layered depth

Blur effects

Beautiful shadows

Excellent spacing

Responsive on desktop and tablet

Animations should enhance usability, never feel gimmicky.

Global Animation Guidelines

Every interaction should feel alive.

Include:

Smooth page transitions

Fade + slide transitions

Staggered component entrances

Hover lift effects

Scale animations

Animated gradients

Floating decorative background elements

Animated icons

Button ripple/press feedback

Soft glowing highlights

Expand/collapse animations

Animated cards

Skeleton loading placeholders

Micro-interactions throughout the application

Use spring animations where appropriate.

Avoid abrupt appearance/disappearance of elements.

Navigation

Navigation between pages should be smooth.

Examples:

Slide transitions

Shared element transitions where possible

Animated sidebar indicator

Smooth active tab movement

Animated breadcrumbs

Animated page titles

Landing / Welcome Screen

The first screen after login should be the most visually impressive page in the application.

This page should feel like a premium product introduction before entering the workspace.

Requirements:

Full-screen hero layout

Animated welcome message

Dynamic greeting section

Floating glass cards

Animated background shapes

Soft moving gradients

Parallax movement on mouse movement

Floating navigation buttons

Buttons that gently bob or float when idle

Smooth magnetic hover effect on buttons

Beautiful hover glow

Animated icons

Cards that subtly tilt with cursor movement

Elegant entrance sequence when page loads

Smooth transition into the dashboard when a navigation button is clicked

The transition from the welcome page to the next page should feel cinematic.

Examples:

Entire page slides away

New page fades in while sliding

Shared button morph

Background transition

Motion continuity

The goal is to create a memorable first impression.

Dashboard Pages

Each page should have:

Smooth loading animations

Animated statistics cards

Interactive charts (UI only)

Hover effects

Expandable widgets

Floating action buttons where appropriate

Animated notifications

Elegant modals

Smooth drawers

Interactive tables

Beautiful empty states

Animated search bars

Animated filter chips

Components

Every reusable component should have polished interactions.

Examples:

Buttons

Hover lift

Glow

Ripple

Spring click animation

Cards

Elevation on hover

Subtle scaling

Border glow

Shadow transitions

Inputs

Animated focus states

Floating labels where appropriate

Smooth validation animations

Tables

Row hover animation

Animated sorting indicators

Smooth pagination

Dialogs

Scale + fade entrance

Blurred backdrop

Spring animation

Sidebar

Animated collapse

Smooth icon transitions

Sliding active indicator

Code Quality

Build reusable components.

Keep files modular.

Use proper TypeScript typing.

Keep animations reusable.

Do not hardcode repetitive styles.

Organize the project cleanly.

Important

Generate only frontend UI code.

Do not create backend code.

Do not create API endpoints.

Do not create Express, Node, Flask, Firebase, Supabase, Prisma, or database files.

Do not implement authentication logic.

Do not implement business logic.

Do not generate fake backend services.

Use placeholder/static data only where required to demonstrate the UI.

The priority is creating an exceptionally polished, interactive, animation-rich frontend that faithfully follows the provided wireframes while elevating them into a production-quality user experience.
